# AtendeFácil

Sistema web para abertura, triagem e acompanhamento de chamados. Trabalho da disciplina Prática Profissional em Análise e Desenvolvimento de Sistemas, Universidade Presbiteriana Mackenzie, Grupo 9.

Repositório: https://github.com/LouisRecheX/Mackenzie-Projeto-grupo-9

Site: https://louisrechex.github.io/Mackenzie-Projeto-grupo-9/

## Como executar no computador

É preciso ter o Node.js 18 ou superior (https://nodejs.org/).

```
npm install
npm run dev
```

Abra o endereço que aparecer no terminal, em geral http://localhost:5173.

Versão de produção:

```
npm run build
npm run preview
```
